# Workflow tips

Before implementing a feature:

1. Read tasks.md to see current progress and avoid duplicate work.
2. Read architecture.md for tech details
3. Read requirements.md and relevant to this feature
4. Inspect existing implementation patterns
5. Identify constraints before coding
6. Summarize requirements before implementation

After implementing a feature:

1. Update the relevant docs if needed.
2. Mark the completed work in `docs/tasks.md`.
3. If a feature has its own design or implementation doc, add a short completion note there too.
4. Keep `docs/tasks.md` as the lightweight progress tracker so you don't need to load every document every time.
