# Requirements

## User requirements

- when creating an entry, I select an emotion and add an optional note
- select from a list of pre-defined emotions
- each emotion must have a name and a colored icon
- must work offline
- save state to the filesystem
- use this app on Android mobile

Optional/later:
- use this app on the web occasionally
- save/load sync file from Google Drive when online
- localization
- statistics
- chart
