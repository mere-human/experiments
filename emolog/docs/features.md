# MVP Features

## Core capabilities

- Emotion entry creation
  - pick an emotion from a predefined list (palette)
  - add an optional note
  - save with current timestamp

- Emotion library
  - built-in set of emotions with names, colors, and icons
  - ability to view the emotion palette

- History view
  - show recent entries in a simple timeline or list
  - display time, emotion, and note preview
  - allow entry editing and deletion

- Local persistence
  - store entries and emotion definitions locally
  - preserve data between app launches
  - offline-first behavior

- Android-friendly UI
  - mobile-optimized layout
  - simple navigation
  - readable colors and accessible touch targets

## Near-term enhancements

- export/import a JSON sync file
- basic settings (default emotion set, theme)
- optional web support as a PWA or web app

## Later roadmap

- statistics and charts for emotion trends
- localization and language support
- Google Drive sync or cloud backup
- customizable emotion sets
